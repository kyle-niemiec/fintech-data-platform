# Planning Docs

`planning/` is the authoritative specification layer for this project.

## Use These Docs For
- Vision and target architecture boundaries.
- Pipeline, event-contract, and data-model intent.
- Security, operations, roadmap sequencing, and requirement coverage.

## Working Rules
- Read relevant planning docs before changing behavior.
- Preserve intent unless explicitly re-scoped.
- If delivery requires temporary deviation, log it in development docs plus `../development/tech-debt.md`.
